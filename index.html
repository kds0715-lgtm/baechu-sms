절임배추 단체문자

장부를 찍으면 연락처를 읽어서 한 번에 보냅니다

1

장부 사진 찍기

장부가 여러 장이면 한 장씩 계속 찍으세요. 찍을 때마다 아래 목록에 더해집니다. 같은 번호는 한 번만 들어갑니다.

2

받는 분 확인

노란 줄은 글씨가 흐려서 확인이 필요한 번호입니다. 장부와 맞는지 보고, 틀리면 "고치기"를 누르세요. 빼고 싶은 분은 이름을 누르세요.

3

보낼 내용 고르기

내용은 직접 고쳐도 됩니다.

번호가 한 명만 들어갈 때
컴퓨터에서 번호 넘겨주기

한 줄에 한 사람씩 "이름 번호" 형식으로 입력하거나 붙여넣으세요. 번호만 써도 됩니다. QR이 나오면 어르신 폰 카메라로 비추세요.

설정 (처음 한 번만)

사진에서 번호를 읽으려면 Anthropic API 키가 필요합니다. 키는 이 휴대폰에만 저장되고 다른 곳에는 저장되지 않습니다.
